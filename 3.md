# Herramientas CI/CD

La Integración Continua (CI) y el Despliegue Continuo (CD) forman la columna vertebral técnica de DevOps, permitiendo validar y desplegar cambios automáticamente.

## Conceptos Clave

- **CI (Integración Continua):** Fusión frecuente de cambios en una rama principal, disparando compilaciones y suites de pruebas automáticas para detectar conflictos tempranamente.
- **CD (Entrega / Despliegue Continuo):**
  - *Continuous Delivery:* El artefacto siempre está validado y listo para desplegar; el paso final a producción requiere autorización manual.
  - *Continuous Deployment:* Todo cambio que supera con éxito el pipeline se despliega en producción de manera 100% automatizada.

## Comparativa de Herramientas

| Herramienta | Tipo | Características Principales | Caso de Uso Común |
| :--- | :--- | :--- | :--- |
| **GitHub Actions** | SaaS / Cloud integrado | Flujos en YAML, integración directa con repositorios GitHub y enorme catálogo en el Marketplace. | Proyectos alojados en GitHub, flujos ágiles. |
| **GitLab CI/CD** | SaaS / Self-Hosted | Solución integral (*all-in-one*), potente gestión de *runners* propios y pipelines paralelos. | Equipos que centralizan su ciclo completo en GitLab. |
| **Jenkins** | Self-Hosted (Open Source) | Ecosistema masivo de plugins, alta madurez y flexibilidad total para scripts complejos. | Infraestructuras tradicionales *on-premise*. |
| **ArgoCD** | GitOps para Kubernetes | Sincronización declarativa entre el estado deseado en Git y el clúster de K8s. | Despliegue continuo en entornos nativos de nube. |
| **Drone CI** | Ligero (Basado en Docker) | Cada paso del pipeline se ejecuta en un contenedor efímero, con mínimo consumo de recursos. | Homelabs y entornos ligeros autosuficientes. |
