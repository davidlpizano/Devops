# Automatización de Procesos en DevOps

La automatización busca erradicar tareas manuales para lograr entornos repetibles, auditables y con una tasa mínima de incidentes.

## Áreas Principales de Automatización

### 1. Infraestructura como Código (IaC)
Permite definir, desplegar y versionar redes, almacenamiento y máquinas virtuales mediante archivos de configuración declarativos.
- **Herramientas:** Terraform, OpenTofu, CloudFormation.
- **Ventaja:** Entornos reproducibles y prevención de desvíos de configuración (*drift*).

### 2. Gestión de Configuraciones
Automatiza la instalación de paquetes, securización del sistema operativo y configuración de servicios tras el aprovisionamiento.
- **Herramientas:** Ansible, Puppet, Chef.
- **Ventaja:** Gestión masiva de nodos de forma idempotente y trazable.

### 3. Contenedores y Empaquetado
Aíslan la aplicación junto a sus dependencias para asegurar consistencia entre el entorno de desarrollo y producción.
- **Herramientas:** Docker, Docker Compose, Podman.
- **Ventaja:** Despliegues inmutables y portables.

### 4. Estrategias de Despliegue sin Caídas (*Zero-Downtime*)
- **Rolling Update:** Reemplazo escalonado de instancias una por una.
- **Blue/Green:** Coexistencia de dos entornos idénticos donde el tráfico conmuta al nuevo entorno una vez comprobada su estabilidad.
- **Canary:** Enrutamiento inicial de un pequeño porcentaje del tráfico (ej. 5%) hacia la nueva versión para validar su rendimiento en producción.
